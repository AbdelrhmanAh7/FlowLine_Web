# Background direction references

These official product homepages were reviewed as visual references. This is a bounded reference set, not a ranking or claim about the best product designs. Flowline uses its own SVG paths, semantic theme tokens, composition, and motion; no logos, screenshots, illustrations, or site assets are reused.

## Flowline adaptation

The four scenes combine soft auroral lenses, a small number of peripheral particles, layered ribbon paths, and a barely visible structural grid. Arabic and English compositions use different sweep directions and path geometry in both light and dark themes. The artwork remains behind a central reading-area mask, uses only Flowline semantic color tokens, and respects the existing reduced-motion and 240 ms interaction limits. Workflow icons and node diagrams are intentionally absent from this background treatment.
