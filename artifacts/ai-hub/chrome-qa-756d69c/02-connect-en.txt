Routing policy

How AI calls choose a route. Only routes you list here are ever used as alternatives — never another key or a server key.

Mode
Manual
Each call uses exactly its chosen model (step, agent, Copilot or the workspace default). No alternatives.
Fallback
If the chosen model keeps failing (rate limits, outages, removed model, no balance), try the listed routes in order. Never after a rejected key, a safety refusal, a disconnected connection or a cancellation.
Free only
Only routes whose price is verified as zero (official pricing page or documented model list). Unknown prices are never treated as free, and no-charge quotas (e.g. a Gemini free-tier key, Cloudflare's daily free Neurons) can't be confirmed per call, so they are refused. If no free route fits, nothing is sent.
Low cost
The cheapest route among the call's own route and the approved pool whose price is KNOWN and within the ceiling. Routes with unknown prices are never picked.
Only use providers that document that API data isn't used for training
Routes that can't guarantee it (gateways with varying upstream terms, providers that train by default or whose terms are unknown) are refused.
Allow AI calls whose price is unknown while a spending cap is set
Off (recommended): such calls are refused before anything is sent, because their cost can't be bounded. Add prices in Settings → Usage & limits instead.

Copilot models

Copilot plans a change with the planning model; if Flowline's validator rejects the plan, up to two repair rounds use the repair model.
